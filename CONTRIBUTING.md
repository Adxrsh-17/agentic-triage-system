# Contributing to Smart Triage AI

Thank you for contributing to the Agentic Clinical Triage Copilot!

## Development Guidelines

1. **Safety First Invariant:**
   - Any modification to risk logic must preserve the core safety invariant: **the system may escalate acuity above the rule floor, but must never de-escalate acuity below what the deterministic red-flag check establishes.**
2. **Offline-First Resilience:**
   - The application and all tests must be runnable offline with zero API keys. External APIs (Groq, Pinecone, Infermedica) must always provide deterministic local fallbacks.
3. **No Metric Fabrication:**
   - Every metric reported in documentation or presentations must be generated by code and backed by an artifact in `docs/results/` or `eval/results/`.
4. **Code Quality & Testing:**
   - Format and lint code with `ruff check .`.
   - Ensure all tests pass with `pytest tests/ -v`.
   - Add property-based tests via `hypothesis` for critical clinical functions.

## Submission Workflow

1. Fork repository and create a feature branch (`git checkout -b feat/my-improvement`).
2. Run test battery: `make test`.
3. Verify evaluation harness: `make eval`.
4. Submit pull request with clear description of clinical safety impact.
